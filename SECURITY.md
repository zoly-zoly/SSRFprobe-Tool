# 🔒 Security Policy

*We take the security of SSRFProbe and its users seriously. Please review this document to understand our supported versions and how to responsibly disclose any vulnerabilities you may find.*

## ✅ Supported Versions

We actively maintain and provide security updates for the following versions of the software. If you are using an older version, please upgrade to ensure you have the latest security patches.

| Version | Support Status |
| :--- | :--- |
| **1.0.x** | 🟢 Actively Supported |
| **< 1.0** | 🔴 No Longer Supported |

---

## 🛑 Reporting a Vulnerability

If you discover a security vulnerability within the codebase or dependencies of SSRFProbe, we kindly ask that you follow these responsible disclosure guidelines:

1. **Keep it Confidential:** Please **do not** create a public GitHub issue, pull request, or social media post regarding the vulnerability. Public disclosure before a patch is available puts all users at risk.
2. **Contact Us Directly:** Send an email detailing the vulnerability to our security team at: 
   👉 `security@yourdomain.com` *(Replace with your actual email address)*
3. **Provide Necessary Details:** To help us reproduce and fix the issue quickly, please include:
   - A clear and detailed description of the vulnerability.
   - The potential impact or risk associated with it.
   - Step-by-step instructions or a minimal Proof-of-Concept (PoC) to reproduce the issue.
   - Any suggested remediations, mitigations, or patches (if applicable).

---

## ⏱️ Response Timeline

We value the time and effort of security researchers. When you submit a report, you can expect the following workflow:

- **Acknowledgment:** We aim to acknowledge receipt of your vulnerability report within **48 hours**.
- **Assessment:** Our team will review the report, confirm its validity, and determine its severity.
- **Remediation & Patching:** We will develop a fix and update the supported branches.
- **Coordinated Disclosure:** Once a patch is released and users have had time to update, coordinated public disclosure will follow, crediting you for the discovery (if desired).
